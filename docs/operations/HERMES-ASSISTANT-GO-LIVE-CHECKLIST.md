# Hermes Assistant Go-Live Checklist

Last updated: 2026-07-30

## Required Gates

- Commercial qualification complete.
- Tenant created.
- Subscription recorded.
- Assistant licence allocated.
- Assistant definition approved.
- WhatsApp number provisioned.
- Knowledge scope reviewed.
- Disclosure policy reviewed.
- Capability policy reviewed.
- Escalation policy reviewed.
- Persona and response design approved.
- Safety policy configured.
- Test environment completed.
- Customer acceptance captured.
- Known limitations recorded.
- Kill switch or suspension route confirmed.
- Human escalation route tested.
- Support owner assigned.

## Public Assistant Additional Gates

- Business Knowledge deployed.
- Public disclosure controls verified.
- Assistant-instance isolation exists.
- Participant identity handling exists.
- Escalation workflow exists.
- Customer acceptance testing passes.

The Parent Assistant must not go live before all public assistant gates pass.

## Launch Monitoring

Monitor:

- connection health;
- response failures;
- unanswered questions;
- hallucinated claims;
- escalation accuracy;
- customer satisfaction;
- average response time;
- human takeover rate;
- unsafe requests;
- knowledge gaps.

## Prohibited At Go-Live Without Future Milestones

- execution;
- email sending;
- Calendar writes;
- ClickUp writes;
- CRM mutations;
- MCP calls;
- autonomous code or policy changes;
- claims of completed actions without execution receipts.
