# Hermes Modular Conversational Test Packs v1

Last updated: 2026-07-30

## Packs

- IP confidentiality
- Capability honesty
- Planning safety
- Conversation continuity
- Business knowledge
- Executive usefulness

Each pack is small, synthetic and focused. Multi-turn tests are used only where
continuity is part of the requirement.

## Mandatory Regression Themes

The packs cover internal architecture requests, Skill-name exposure, prompt and
routing disclosure, deployment details, credentials, Calendar authorisation,
email send counts, reminders, Calendar-versus-Gmail decision planning,
multi-turn Calendar continuity, unsafe sequencing, high-ambition revenue
planning, missing programme details, false action claims, execution bypass
attempts, meeting hallucination traps, no approved plans and no executed
planning actions.
