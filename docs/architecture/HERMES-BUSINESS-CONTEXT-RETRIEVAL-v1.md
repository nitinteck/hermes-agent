# Hermes Business Context Retrieval v1

Last updated: 2026-07-30

## Purpose

Business context retrieval provides the minimum relevant owner-safe context to
Executive Orchestration.

## Filters

Retrieval filters by tenant, user, active business/brand, entity relevance,
request purpose, sensitivity, disclosure channel, verification status,
freshness, confidence and effective dates.

## Provenance

Context uses safe source categories and digests. Normal WhatsApp does not expose
record IDs, raw registry structure or restricted business context.

Conflicts are surfaced for owner review rather than silently resolved. Stale
facts are excluded from current context and require confirmation where material.
